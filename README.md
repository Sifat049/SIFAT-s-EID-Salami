# 🌙 Sifat's Eid Salami

A fun Eid salami spin wheel. Spin, win a prize, enter your bKash/Nagad number, and Sifat gets an instant phone notification to send your salami.

## Features
- Animated Eid theme (crescent moon, lanterns, stars)
- 6-slice prize wheel with confetti on win
- Number check (Bangladesh format `01XXXXXXXXX`)
- Instant push notification via [ntfy.sh](https://ntfy.sh)
- Works on mobile and desktop

## Setup (for Sifat)
1. Install the free **ntfy** app on your phone.
2. Subscribe to the topic written in `index.html` as `NTFY_TOPIC`.
3. Done. Every claim appears as a notification with the number and amount.

Change prizes or chances in the `PRIZES` list at the top of the script.
